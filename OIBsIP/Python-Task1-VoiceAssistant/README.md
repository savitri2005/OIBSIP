# 🎙️ Voice Assistant - Python Task 1

## 📋 Project Overview
This is a **Voice Assistant** built in Python as part of the **Oasis Infobyte Python Programming Internship** (Task 1 - Beginner Tier).

## ✨ Features Implemented
- [x] 🎤 Voice input using microphone
- [x] 🔊 Text-to-speech responses
- [x] 👋 Greeting based on time of day
- [x] ⏰ Tell current time
- [x] 📅 Tell today's date
- [x] 🔍 Web search on Google
- [x] ❌ Graceful error handling

## 🛠️ Tech Stack
- Python 3.11
- SpeechRecognition
- pyttsx3
- datetime
- webbrowser
